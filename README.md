# Mathematics of Poker, Visualized

Exact computational explorations of Chen & Ankenman's *The Mathematics of
Poker*, organized by game family, each with an interactive self-contained
explorer. **Site: https://joeypopelka.github.io/mathematics-of-poker-visualized/**

> Repo reorganization in progress (see [PLAN.md](PLAN.md)). Current projects:

| Family | Book chapters | Folder |
|---|---|---|
| The AKQ game, no-limit | 15 + appendix | [`akq/nl/`](akq/nl/) |
| [0,1] games | 11, 16–18 | [`zero-one/`](zero-one/) |
| Jam-or-fold | 12 | [`jam-or-fold/`](jam-or-fold/) |
| Tournaments | 26–28 | [`tournaments/`](tournaments/) |

Each folder has its own README with reproduction instructions and a REPORT.md
with findings.
